Math for Homey

Math adds value-focused Flow cards for calculations, formulas, unit conversion, comparisons, and logic checks.

Key features
- Calculate values with operators like add, subtract, multiply, divide, modulo, and power
- Evaluate expressions with math-style syntax
- Convert units such as length, mass, temperature, speed, energy, and pressure
- Apply math functions like round, min, max, clamp, average, random, and mapRange
- Read number variables as values for Advanced Flow

Typical usage
- Build a value in one card and pass the result into the next card
- Use Logic variables or dropped tags as input values
- Keep flows cleaner by working with values first and only storing data where needed elsewhere in your flow

Notes
- This app focuses on number values
- Some cards that directly wrote to variables are kept only for backward compatibility
